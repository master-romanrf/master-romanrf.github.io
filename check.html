Возьму твою текущую главную прямо с сайта и добавлю в футер одну ссылку на справочник. Больше ничего не тронется: ни квиз, ни Метрика, ни стили.

🗺️sitemap.xml
Чистый XML с двумя адресами: главная и справочник. Именно этот файл принимается в поле «Файлы Sitemap».
Нажми «Собрать» — подготовлю sitemap.xml
🤖robots.txt
Правила для роботов с указанием sitemap и очисткой служебных параметров, чтобы страницы не дублировались в индексе.
Нажми «Собрать» — подготовлю robots.txt
🖼️og-image.svg
Картинка для репостов в MAX, Telegram и Одноклассниках — в цветах сайта: тёмный фон, оранжевый код, зелёная цена.
Нажми «Собрать» — подготовлю og-image.svg
Как загрузить собранный файл:
  1. Нажми «Скачать» — файл попадёт в «Загрузки» телефона.
  2. GitHub → репозиторий → Add file → Upload files.
  3. Выбери скачанный файл → Commit changes.
  4. Вернись сюда и нажми «Проверить снова».
Если «Скачать» не срабатывает во встроенном просмотре — открой эту страницу в Chrome или нажми «Копировать» и вставь текст в файл на GitHub.

Что отправить в Вебмастер

1. Индексирование → Файлы Sitemap
https://master-romanrf.github.io/sitemap.xml
Сюда идёт только XML-файл. Адрес страницы справочника сюда вставлять нельзя — будет «некорректный».
2. Индексирование → Переобход страниц
https://master-romanrf.github.io/spravochnik.html
Сюда — адреса страниц: справочник и главная. Это просьба к роботу прочитать их заново сегодня.
